# PDF backend contract fixtures

The files in this directory are Base64-encoded so the same test assets can be
loaded by JVM, Kotlin/Native, JS, and Wasm adapters without Git binary-patch
handling. Decode `NAME.pdf.base64` to obtain the original PDF bytes.
